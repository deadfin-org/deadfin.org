A Jellyfin-compatible media server written in Go.

Deadfin serves the Jellyfin 12.0 API. Use your Jellyfin apps with Deadfin. Most familiar flows work unchanged; see the client matrix for tested paths and known alpha gaps.

Quick start Source on GitHub

  • One Go process. No .NET runtime. Multi-arch image (amd64 and arm64) with Jellyfin's FFmpeg build.
  • Hardware transcoding. Intel QSV and VAAPI, NVIDIA NVENC, with HDR10, HLG and Dolby Vision tone mapping.
  • Moves in from Jellyfin. A one-way importer brings users, watch state, playlists, collections and libraries. It only reads Jellyfin's files.
  • SQLite or PostgreSQL. SQLite by default, with no setup.

Quick start

Deadfin listens on TCP 8096 and answers client discovery on UDP 7359. All its state lives in /var/lib/deadfin in the container. The container runs as UID/GID 65532.

  1. Get a TMDb API key

    Movie and TV metadata and artwork come from TMDb. Each Deadfin server uses its own key. A free v3 key takes a few minutes at themoviedb.org/settings/api. Set it before the first library scan.

  2. Make the data directory

    The container runs as UID/GID 65532:

    mkdir -p ./deadfin/data
sudo chown 65532:65532 ./deadfin/data

    The image includes deadfin-web, the web client. For the complete stock interface with the admin dashboard, use jellyfin-web instead.

  3. Run Deadfin

    :alpha follows the newest release or release candidate. To control upgrades, put a tag from the tags page in its place, for example ghcr.io/deadfin-org/deadfin:v0.3.0-rc.8.

    # compose.yaml
services:
  deadfin:
    image: ghcr.io/deadfin-org/deadfin:alpha
    restart: unless-stopped
    ports:
      - "8096:8096"
      - "7359:7359/udp"
    environment:
      TMDB_API_KEY: "your-key"   # from step 1: movie and TV metadata and art
    volumes:
      - ./deadfin/data:/var/lib/deadfin
      - /srv/media:/media:ro
    docker compose up -d
    The same with docker run 
    docker run -d --name deadfin --restart unless-stopped \
  -p 8096:8096 -p 7359:7359/udp \
  -e TMDB_API_KEY=your-key \
  -v "$PWD/deadfin/data:/var/lib/deadfin" \
  -v /srv/media:/media:ro \
  ghcr.io/deadfin-org/deadfin:alpha

  4. Finish setup

    Open http://<host>:8096/web/ from your local network and complete the startup wizard. Behind a reverse proxy, use the one-time setup link that Deadfin prints in its log.

The install guide covers volumes, PostgreSQL, reverse proxies, hardware transcoding, adding libraries and upgrades. To move from Jellyfin, read importing from Jellyfin.

Status: alpha

Deadfin is alpha software. Back up your data, expect defects, and keep your Jellyfin server around while you try it.

Works today

First-run setup, sign-in and QuickConnect, library scans with TMDb, TheAudioDB and AniList metadata, browsing and search, direct play, HLS transcoding, external and embedded subtitles (including burn-in), resume and played state, playlists and collections, music, trickplay previews, and the Jellyfin importer.

Live TV, DVR and SyncPlay are on the roadmap.
